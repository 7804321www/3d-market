# 3D Market – сайт з продажу 3D-моделей (лабораторна робота №5)

Каталог моделей із пошуком, фільтрами (категорія, формат, ціна), сортуванням, кошиком,
промокодами (`MODEL10`, `STUDENT15`) і формою замовлення.

## Структура
- `index.html` – інтерфейс сайту (відкрити в браузері)
- `src/shop.js` – вся логіка (пошук, фільтри, сортування, кошик, промокоди, валідація)
- `tests/shop.test.js` – модульні та інтеграційні тести логіки
- `tests/ui.test.js` – функціональні тести інтерфейсу (jsdom)

## Запуск тестів (потрібен Node.js 20+)
```
npm install
npm test
npm run coverage
```
